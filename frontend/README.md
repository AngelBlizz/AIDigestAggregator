# AI Digest Aggregator - Frontend

Фронтенд для интеллектуальной системы агрегации и анализа новостного контента с автоматическим формированием тематических дайджестов.

## Технологии

- React 17
- TypeScript
- Material UI
- Redux Toolkit
- Recharts для визуализации данных
- Axios для запросов к API

## Установка и запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Для разработки запустите:
   ```bash
   npm start
   ```

3. Для сборки проекта:
   ```bash
   npm run build
   ```

## Необходимые зависимости

Если после установки возникают ошибки с типами, убедитесь, что установлены следующие пакеты:

```bash
npm install recharts @types/recharts
```

## Структура проекта

- `src/components` - Компоненты приложения
- `src/pages` - Страницы приложения
- `src/services` - Сервисы для работы с API
- `src/types` - TypeScript типы и интерфейсы
- `src/store` - Redux-хранилище и редюсеры
- `src/utils` - Вспомогательные функции
- `src/App.tsx` - Корневой компонент с маршрутизацией

## Функциональность фронтенда

1. **Аутентификация и авторизация пользователей**
   - Регистрация и вход в систему
   - Управление профилем пользователя

2. **Управление дайджестами**
   - Просмотр сгенерированных дайджестов
   - Генерация новых дайджестов с настраиваемыми параметрами

3. **Аналитика контента**
   - Анализ тональности
   - Распределение по темам
   - Тренды в динамике
   - Статистика по источникам

4. **Расширенный поиск**
   - Фильтрация по различным параметрам (источник, тема, тональность)
   - Сортировка результатов
   - Просмотр детальной информации о статьях

5. **Управление темами**
   - Создание и редактирование тем
   - Выбор тем для персонализации контента
