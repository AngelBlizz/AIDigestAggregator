# AI Агрегатор Дайджестов Новостей

Интеллектуальная система для агрегации новостного контента, многоязычного анализа и автоматической генерации тематических дайджестов.

## Обзор Проекта

Система предоставляет:
- Автоматическую агрегацию новостного контента из различных источников
- Интеллектуальный анализ и классификацию контента с использованием NLP
- Генерацию персонализированных тематических дайджестов
- Удобный пользовательский интерфейс для потребления контента
- Мультиязычную поддержку (русский и английский языки)
- Аналитику и визуализацию данных

## Ключевые Возможности

### Агрегация Контента
- Сбор новостей из множества источников с настраиваемыми селекторами
- Автоматическая обработка и нормализация контента
- Система управления источниками через административный интерфейс
- Защита от блокировки через ротацию User-Agent и задержки между запросами
- Интеграция с внешними API (NewsAPI.org, GDELT Project, Media Stack API)
- Обработка JavaScript-зависимых источников через Selenium

### Обработка Естественного Языка (NLP)
- Анализ тональности текста с детальными метриками
- Извлечение ключевых слов и важных фраз
- Определение именованных сущностей (люди, организации, места)
- Автоматическое генерирование краткого содержания статей
- Поддержка русского и английского языков
- Семантическое сравнение текстов и определение дубликатов
- Кластеризация и группировка похожих новостей

### Персонализация
- Система пользовательских предпочтений по темам
- Умная фильтрация контента на основе интересов пользователя
- Управление персональными дайджестами
- Адаптивное обучение на основе действий пользователя
- A/B тестирование алгоритмов ранжирования для улучшения рекомендаций
- Настраиваемая частота и размер дайджестов

### Аналитика
- Распределение тональности контента во времени
- Анализ трендов и популярных тем
- Статистика по источникам и авторам
- Визуализация данных с помощью интерактивных графиков
- Отслеживание популярности тем и частоты их упоминаний
- Выявление важных событий через анализ всплесков интереса

## Технический Стек

### Backend
- **Python 3.9+**: Основной язык программирования
- **FastAPI**: Высокопроизводительный веб-фреймворк для API
- **SQLAlchemy**: ORM для работы с базой данных
- **Pydantic**: Валидация данных и сериализация
- **SQLite/PostgreSQL**: Системы управления базами данных
- **NLP инструменты**:
  - SpaCy: Продвинутая библиотека для обработки естественного языка
  - NLTK: Библиотека для анализа текстов
  - TextBlob: Простая библиотека для обработки текстов
- **Celery**: Система распределенных фоновых задач
- **Redis**: Брокер сообщений для Celery и кэширование
- **BeautifulSoup**: Библиотека для парсинга HTML
- **Selenium**: Для обработки JavaScript-зависимых источников

### Frontend
- **React 18**: Библиотека для создания пользовательского интерфейса
- **TypeScript**: Типизированный JavaScript для надежного кода
- **Redux Toolkit**: Управление состоянием приложения
- **Material-UI**: Библиотека компонентов с современным дизайном
- **React Router**: Маршрутизация на клиентской стороне
- **Axios**: HTTP-клиент для работы с API
- **Recharts**: Библиотека для визуализации данных

```
backend/
├── app/

│   │   └── endpoints/    # Конечные точки API для различных модулей

│   ├── services/         # Бизнес-логика и сервисы
│   └── tasks/            # Фоновые задачи Celery
└── main.py               # Точка входа приложения
```

### Модели Данных
- **User**: Информация о пользователях и аутентификация
- **Topic**: Тематические категории для статей
- **Article**: Новостные статьи с метаданными и результатами NLP-анализа
- **Digest**: Персонализированные дайджесты контента
- **NewsSource**: Настройки источников новостей для скраперов
- **DigestArticle**: Связующая модель между дайджестами и статьями

### Ключевые Сервисы
- **news_scraper.py**: Система сбора новостей с настраиваемыми селекторами
  - Конфигурация CSS-селекторов для разных элементов страницы
  - Защита от блокировки через ротацию User-Agent
  - Обработка ошибок и повторные попытки при неудачных запросах
  - Проверка наличия дубликатов статей перед сохранением
  - Поддержка прокси-серверов для обхода блокировок
  
- **nlp_analyzer.py**: Сервис для анализа текстового содержимого:
  - Определение языка (русский/английский)
  - Анализ тональности с детальными метриками
  - Извлечение ключевых слов и фраз
  - Определение именованных сущностей
  - Создание краткого содержания
  - Пакетная обработка для повышения производительности
  - Многопоточная обработка для CPU-интенсивных операций
  - Кэширование результатов для повторного использования
  
- **news_aggregator.py**: Объединение и категоризация новостей
  - Интеграция с различными новостными API
  - Алгоритмы кластеризации для группировки схожих новостей
  - Выявление трендов и популярных тем
  - Отказоустойчивость при временной недоступности API
  - Ротация API-ключей для обхода ограничений по частоте запросов
  
- **digest_generator.py**: Создание персонализированных дайджестов
  - Персонализация на основе интересов пользователя
  - Алгоритмы ранжирования статей по релевантности
  - Учет истории взаимодействия пользователя
  - Обучение на основе обратной связи
  - A/B тестирование алгоритмов ранжирования

### API Endpoints
- `/api/v1/auth`: Аутентификация и управление пользователями
- `/api/v1/digests`: Работа с дайджестами
- `/api/v1/topics`: Управление тематическими категориями
- `/api/v1/articles`: Доступ к отдельным статьям
- `/api/v1/scraper`: Управление скраперами источников
- `/api/v1/analytics`: Аналитические данные и статистика
- `/api/v1/stats`: Базовые статистические метрики

### Фоновые задачи
- **celery_app.py**: Настройка Celery для фоновых задач
- **news_tasks.py**: Задачи, выполняемые по расписанию:
  - Регулярный сбор новостей (каждые 3 часа)
  - Анализ статей (каждые 30 минут)
  - Генерация дайджестов (ежедневно)
  - Агрегация новостей через API (раз в час)

### Отказоустойчивость и масштабируемость
- Механизм повторных попыток с экспоненциальной задержкой
- Отказоустойчивые паттерны (Circuit Breaker, Bulkhead)
- Резервные стратегии при недоступности внешних сервисов
- Кэширование критичных данных для работы офлайн
- Возможность горизонтального масштабирования компонентов

## Инструкции по Установке

### Подготовка Backend
1. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # В Windows: venv\Scripts\activate
```

2. Установите зависимости:
```bash
pip install -r backend/requirements.txt
```

3. Установите модели SpaCy:
```bash
python -m spacy download en_core_web_sm
python -m spacy download ru_core_news_sm  # для русского языка
```

4. Запустите сервер разработки:
```bash
cd backend
uvicorn app.main:app --reload
```

### Подготовка Frontend
1. Установите зависимости:
```bash
cd frontend
npm install
```

2. Запустите сервер разработки:
```bash
npm start
```

### Запуск фоновых задач (опционально)
1. Запустите Redis:
```bash
redis-server
```

2. Запустите воркер Celery:
```bash
cd backend
celery -A app.core.celery_app worker --loglevel=info
```

3. Запустите планировщик Celery:
```bash
cd backend
celery -A app.core.celery_app beat --loglevel=info
```

## Системные Требования
- Python 3.9+
- Node.js 14+ и npm
- Redis (для Celery)
- Достаточно оперативной памяти для NLP-моделей (рекомендуется от 4 ГБ)

## Поток данных в системе
1. **Сбор данных**: Периодически запускаются фоновые задачи (Celery)
2. **Скраперы и API-клиенты**: Получают новые статьи из различных источников
3. **NLP-анализ**: Обработка контента, извлечение метаданных
4. **Генерация дайджестов**: Создание персонализированных подборок для пользователей
5. **API**: Предоставление доступа к данным через HTTP-интерфейс
6. **Фронтенд**: Визуализация информации и взаимодействие с пользователем
