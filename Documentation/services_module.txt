# Документация модуля services

## Описание

Модуль `services` содержит бизнес-логику приложения, выполняя основные функциональные задачи системы новостного агрегатора. Этот модуль отвечает за сбор новостей из различных источников, анализ контента с помощью NLP, генерацию дайджестов и другие ключевые функции системы.

## Основные компоненты

### 1. news_scraper.py

**Назначение**: Сбор новостей из различных источников.

**Ключевые классы**:
- `NewsSource` - представляет отдельный источник новостей с настройками для парсинга
- `NewsScraper` - основной класс для сбора новостей
- `ScraperConfig` - конфигурация скрапера с настройками для всех источников
- `NewsArticleExtractor` - класс для извлечения текста статей из HTML

**Основные функции**:
- `scrape_source()` - сбор новостей из конкретного источника
- `scrape_all_sources()` - сбор новостей из всех источников для заданной темы
- `scrape_for_all_topics()` - сбор новостей для всех тем
- `_parse_date()` - обработка различных форматов дат
- `_clean_text()` - очистка и форматирование собранного текста
- `get_full_article_content()` - загрузка полного текста статьи по URL
- `verify_source()` - проверка доступности и валидности источника
- `update_scraper_stats()` - обновление статистики работы скрапера

**Обработка ошибок**:
- Механизм повторных попыток при временных сбоях
  ```python
  def _scrape_with_retry(self, url, max_retries=3, delay=2):
      for attempt in range(max_retries):
          try:
              response = requests.get(url, headers=self._get_random_headers())
              return response
          except (RequestException, ConnectionError) as e:
              self.logger.warning(f"Attempt {attempt+1} failed: {str(e)}")
              if attempt < max_retries - 1:
                  time.sleep(delay * (attempt + 1))  # Экспоненциальная задержка
      raise ScraperException(f"Failed to scrape {url} after {max_retries} attempts")
  ```
- Обработка специфических ошибок разных источников
- Логирование всех этапов сбора для отладки

**Конфигурация и настройки**:
- Настройка задержек между запросами для каждого источника
- Конфигурация CSS-селекторов для разных элементов страницы
- Настройка глубины сканирования для каждого источника
- Стратегии обхода систем защиты от скрапинга

**Особенности**:
- Использование различных селекторов для разных источников
- Защита от блокировки через ротацию User-Agent
- Обработка ошибок и повторы при неудачах

- Поддержка прокси-серверов для обхода блокировок

### 2. nlp_analyzer.py

**Назначение**: Анализ текста новостей с использованием NLP.

**Ключевые классы**:
- `NLPAnalyzer` - основной класс для анализа текста
- `SentimentAnalyzer` - специализированный класс для анализа тональности

- `EntityRecognizer` - класс для распознавания именованных сущностей
- `TextSummarizer` - класс для создания резюме текста

**Основные функции**:
- `analyze_sentiment()` - анализ тональности текста
- `extract_keywords()` - извлечение ключевых слов
- `extract_entities()` - извлечение именованных сущностей (люди, организации, локации)
- `generate_summary()` - создание краткого резюме статьи
- `analyze_article()` - выполнение полного анализа статьи
- `batch_analyze()` - пакетный анализ множества статей
- `compute_text_similarity()` - вычисление семантического сходства между текстами
- `categorize_text()` - определение категории текста
- `detect_language()` - определение языка текста

**Логирование и метрики**:
- Подробное логирование каждого этапа анализа
- Сбор метрик производительности для каждого типа анализа
- Логирование ошибок моделей и исключительных ситуаций
- Отслеживание времени выполнения различных этапов

**Оптимизация производительности**:
- Использование пакетной обработки для уменьшения накладных расходов
  ```python
  def batch_analyze_sentiment(self, texts, batch_size=32):
      results = []
      for i in range(0, len(texts), batch_size):
          batch = texts[i:i+batch_size]
          batch_results = self.nlp_model.pipe(batch)
          results.extend(self._process_sentiment_batch(batch_results))
      return results
  ```
- Многопоточная обработка для CPU-интенсивных операций
- Асинхронное выполнение независимых задач
- Кэширование результатов анализа для повторного использования

**Особенности**:
- Использование модели SpaCy для анализа текста
- Многоязычная поддержка (русский и английский языки)
- Кэширование результатов для улучшения производительности
- Асинхронная обработка для больших объемов данных
- Адаптивный выбор моделей в зависимости от характеристик текста
- Возможность использования внешних API для специализированного анализа
- Обработка неструктурированного и полуструктурированного текста

**Основные функции**:
- `generate_digest_for_user()` - создание дайджеста для конкретного пользователя
- `generate_all_digests()` - создание дайджестов для всех пользователей
- `get_relevant_articles()` - отбор релевантных статей для пользователя
- `rank_articles()` - ранжирование статей по релевантности и важности
- `create_digest_from_articles()` - формирование дайджеста из отобранных статей
- `format_digest_for_email()` - форматирование дайджеста для отправки по email
- `schedule_digest_generation()` - планирование создания дайджеста

- `learn_from_user_feedback()` - обучение на основе обратной связи

**Алгоритмы ранжирования**:
- На основе интересов пользователя (подписки на темы)
- С учетом истории чтения и взаимодействия

**Настройка и конфигурация**:

- Конфигурация частоты генерации (ежедневно, еженедельно)
- Настройка весовых коэффициентов для различных факторов ранжирования
- Параметры баланса между разнообразием и фокусировкой дайджеста

**Обработка ошибок**:
- Обработка ситуаций с отсутствием релевантных статей

**Особенности**:

- Ранжирование статей по нескольким критериям
- Фильтрация дубликатов и похожих новостей

```python
class BaseService:
    def __init__(self):
```

## Основные потоки данных

1. **Сбор новостей**:
   ```
   NewsScraper -> NLPAnalyzer -> NewsAggregator -> Модели базы данных
   ```

2. **Генерация дайджестов**:
   ```
   NewsAggregator -> DigestGenerator -> Модели базы данных -> Уведомления пользователя
   ```

3. **Аналитика контента**:
   ```
   Модели базы данных -> NLPAnalyzer -> Аналитические представления -> Рекомендации
   ```

4. **Взаимодействие пользователя**:
   ```
   Действия пользователя -> Обновление предпочтений -> DigestGenerator
   ```

## Обработка ошибок и отказоустойчивость

### Общая стратегия обработки ошибок:

```python
class ServiceException(Exception):
    """Базовый класс для исключений сервисного слоя"""
    
class ResourceNotFoundException(ServiceException):
    """Исключение для случаев, когда ресурс не найден"""
    
class ExternalServiceException(ServiceException):
    """Исключение при ошибках взаимодействия с внешними сервисами"""

def with_error_handling(max_retries=3, retry_delay=1):
    """Декоратор для обработки ошибок с автоматическими повторами"""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except (ConnectionError, Timeout, RequestException) as e:
                    last_exception = e
                    logger.warning(f"Attempt {attempt+1} failed: {str(e)}")
                    if attempt < max_retries - 1:
                        time.sleep(retry_delay * (2 ** attempt))  # Экспоненциальная задержка
            
            logger.error(f"All {max_retries} attempts failed", exc_info=last_exception)
            raise ExternalServiceException(f"Operation failed after {max_retries} attempts") from last_exception
        return wrapper
    return decorator
```

### Методы обеспечения отказоустойчивости:
- Механизм повторных попыток с экспоненциальной задержкой
- Отказоустойчивые паттерны (Circuit Breaker, Bulkhead)
- Резервные стратегии при недоступности внешних сервисов
- Проверки состояния и самовосстановление
- Кэширование критичных данных для работы офлайн
