# Руководство по настройке и запуску скрапинга в AI News Digest Aggregator

## Диагностика проблем скрапинга

Если вы столкнулись с проблемами при скрапинге новостей, такими как:
```
Ограничено или запрещено доступом к https://www.bloomberg.com/technology, ожидание перед повтором
Не удалось доступиться к https://www.bloomberg.com/technology после нескольких повторов
Не найдено статей для темы Technology из любого источника
```

Это указывает на блокировку доступа к новостным сайтам. Причины могут быть следующие:
1. Блокировка по IP-адресу
2. Обнаружение автоматического скрапинга
3. Капча или другие методы защиты сайта
4. Неправильно настроенные API ключи

## Пошаговая настройка скрапинга

### Шаг 1: Настройка файла .env

1. Перейдите в директорию `backend`
2. Создайте файл `.env` на основе `.env.example` (или запустите `python scraper_diagnostic.py`, который создаст пример файла)
3. Заполните следующие параметры:

```
# API ключи для новостных источников
NEWS_API_KEY=ваш-ключ-newsapi
NYTIMES_API_KEY=ваш-ключ-nytimes

# Настройки для системы прокси и скрапинга
USE_PROXIES=true
PROXY_ROTATION=false

# Настройки прокси (если у вас есть доступ к прокси)
HTTP_PROXY=http://username:password@proxy-server:port
HTTPS_PROXY=https://username:password@proxy-server:port

# Настройки времени ожидания между запросами (в секундах)
MIN_REQUEST_DELAY=3.0
MAX_REQUEST_DELAY=8.0

# Максимальное количество повторных попыток при ошибках
MAX_RETRIES=5
```

### Шаг 2: Получение API ключей

1. **NewsAPI**:
   - Зарегистрируйтесь на сайте https://newsapi.org/
   - Получите бесплатный API ключ (доступно 100 запросов в день)
   - Вставьте ключ в файл .env в параметр `NEWS_API_KEY`

2. **New York Times API**:
   - Зарегистрируйтесь на https://developer.nytimes.com/
   - Создайте новое приложение и запросите ключ API для "Top Stories API"
   - Вставьте ключ в файл .env в параметр `NYTIMES_API_KEY`

### Шаг 3: Настройка прокси (рекомендуется)

Для решения проблем с блокировкой рекомендуется использовать прокси:

1. **Бесплатные прокси**:
   - Можно найти бесплатные прокси на сайтах like https://free-proxy-list.net/
   - Но они часто нестабильны и могут быстро перестать работать

2. **Платные прокси**:
   - Более надежный вариант - использовать платные прокси-сервисы
   - Например, BrightData, Oxylabs, SmartProxy и др.
   - Стоимость обычно начинается от $10-15 в месяц

3. **Ротация прокси**:
   - Если у вас есть несколько прокси, включите ротацию:
   ```
   PROXY_ROTATION=true
   HTTP_PROXY_LIST=http://proxy1:port,http://proxy2:port,http://proxy3:port
   ```

### Шаг 4: Улучшение скрапера

Запустите скрипт улучшения скрапера, который добавляет поддержку прокси и другие улучшения:

```
cd backend
python scraper_enhancement.py
```

### Шаг 5: Диагностика скрапера

Запустите скрипт диагностики, чтобы проверить доступность новостных источников и настройки:

```
cd backend
python scraper_diagnostic.py
```

### Шаг 6: Запуск скрапинга

Для запуска скрапинга вы можете использовать следующие методы:

1. **Через API**:
   ```
   http://localhost:8000/api/v1/news/scrape
   ```

2. **Через панель управления**:
   - Перейдите в раздел "Сканер" в основном меню
   - Нажмите "Запустить сканер"

3. **Через скрипт**:
   ```
   cd backend
   python -c "from app.services.news_scraper import NewsScraper; from app.db.session import get_db; from app.models.models import Topic; db = next(get_db()); scraper = NewsScraper(db); topics = db.query(Topic).all(); for topic in topics: scraper.scrape_all_sources(topic)"
   ```

## Решение распространенных проблем

### Проблема 1: Блокировка доступа

Симптомы:
- Ошибки "Ограничено или запрещено доступом"
- Не удается получить статьи

Решения:
1. Настройте прокси как указано выше
2. Увеличьте задержки между запросами:
   ```
   MIN_REQUEST_DELAY=5.0
   MAX_REQUEST_DELAY=15.0
   ```
3. Используйте больше User-Agent (они автоматически добавлены скриптом улучшения)

### Проблема 2: Неправильные селекторы

Симптомы:
- "Не найдены элементы с основным селектором"
- Статьи скрапятся, но без содержимого

Решение:
1. Сайты часто меняют свою структуру HTML
2. Обновите селекторы в `app/services/news_scraper.py` в методе `_initialize_sources`
3. Используйте инструменты разработчика браузера (F12) для определения правильных селекторов

### Проблема 3: Ограничения API

Симптомы:
- Ошибки доступа к API ключам
- Превышение лимита запросов

Решения:
1. Убедитесь, что вы правильно ввели API ключи в файл .env
2. У бесплатных аккаунтов NewsAPI есть ограничение в 100 запросов в день
3. Рассмотрите возможность использования платных планов для увеличения лимита

## Альтернативные источники новостей

Если вы продолжаете сталкиваться с проблемами при прямом скрапинге, рассмотрите использование:

1. **RSS-каналов**:
   - Многие новостные сайты предоставляют RSS-каналы (например, Хабр)
   - Они обычно меньше защищены от скрапинга

2. **API Google News**:
   - Рассмотрите возможность использования API для агрегации новостей

3. **Другие источники новостей**:
   - Medium API
   - Dev.to API
   - Reddit API для технических сабреддитов

## Советы для продвинутых пользователей

1. **Используйте headless браузер**:
   - Для сложных сайтов с JavaScript, рассмотрите возможность использования Selenium или Playwright

2. **Настройка ротации User-Agent**:
   - Добавьте больше User-Agent в класс скрапера для лучшей маскировки

3. **Настройка IP-ротации**:
   - Используйте сервисы, которые предоставляют автоматическую ротацию IP-адресов

4. **Распределенный скрапинг**:
   - Запускайте скрапинг из разных географических локаций для снижения нагрузки на каждый IP

## Заключение

Скрапинг новостных сайтов может быть сложной задачей из-за растущих мер защиты от автоматизированного доступа. Использование комбинации методов, описанных выше, должно помочь вам преодолеть большинство проблем.

Если у вас продолжаются проблемы, рассмотрите возможность модификации кода скрапера для работы с конкретными сайтами или обратитесь к разработчикам для получения персонализированного решения.
