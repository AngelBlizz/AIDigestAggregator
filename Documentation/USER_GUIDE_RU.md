## Начало работы

### Создание аккаунта и вход

1. Перейдите на URL приложения
2. Нажмите «Регистрация» для создания нового аккаунта
3. Заполните необходимую информацию (электронная почта, имя пользователя, пароль)
4. Подтвердите свою электронную почту, если требуется
5. Войдите, используя свои учетные данные

### Начальная настройка

После первого входа вам будет предложено:
1. Выбрать интересующие темы
2. Настроить предпочтения уведомлений
3. Настроить вид панели управления

## Панель пользователя

Главная панель отображает:
- Последние статьи на основе ваших предпочтений по темам
- Ваши последние дайджесты
- Популярные темы
- Системные уведомления

**Быстрые действия:**
- Щелкните на любой статье, чтобы просмотреть ее полное содержание
- Используйте кнопку «Создать дайджест» для генерации нового дайджеста
- Доступ к боковому меню для дополнительных функций

## Поиск и фильтрация статей

### Базовый поиск

1. Нажмите на значок поиска в панели навигации
2. Введите ключевые слова в поле поиска
3. Нажмите Enter или нажмите кнопку поиска

### Расширенная фильтрация

На странице результатов поиска:
1. Используйте панель фильтров слева
2. Фильтруйте по:
   - Диапазону дат
   - Темам
   - Источникам
   - Оценке тональности
   - Ключевым словам
3. Примените фильтры для сужения результатов
4. Сохраните фильтры поиска для будущего использования, нажав «Сохранить фильтр»

## Управление дайджестами

### Просмотр дайджестов

1. Перейдите в «Дайджесты» в главном меню
2. Посмотрите список всех ваших дайджестов со статусом (прочитано/непрочитано)
3. Нажмите на любой дайджест, чтобы просмотреть его полное содержание

### Создание нового дайджеста

1. На странице дайджестов нажмите «Создать новый дайджест»
2. На странице генератора дайджестов:
   - Выберите темы для включения
   - Выберите источники новостей (по желанию)
   - Установите временной диапазон (1-30 дней)
   - Укажите максимальное количество статей (5-50)
   - Настройте параметры анализа контента:
     - Включение анализа тональности
     - Включение анализа ключевых слов
     - Фильтры диапазона тональности
3. Нажмите «Создать дайджест» для создания вашего персонализированного дайджеста
4. Дождитесь, пока система составит ваш дайджест

### Управление существующими дайджестами

- Отметьте дайджесты как прочитанные/непрочитанные
- Удалите ненужные дайджесты
- Поделитесь дайджестами по электронной почте или через открытую ссылку

## Подписки на темы

### Управление темами

1. Перейдите в «Мои темы» в главном меню
2. Просмотрите ваши текущие подписки на темы
3. Добавьте новые темы, нажав «Добавить тему»
4. Удалите темы, которые вас больше не интересуют

### Создание пользовательских тем

1. На странице тем нажмите «Создать пользовательскую тему»
2. Укажите название и описание
3. Определите ключевые слова, связанные с темой
4. Установите частоту обновлений (как часто вы хотите получать контент)
5. Сохраните вашу пользовательскую тему

## Сканер новостей

### Запуск сканера

1. Перейдите в «Сканер» в главном меню
2. Просмотрите доступные источники новостей
3. Нажмите «Запустить сканер» для сбора новых статей по всем вашим темам
4. Или выберите конкретную тему и запустите сканер только для этой темы

### Просмотр результатов сканирования

1. После запуска сканера появится сообщение о статусе
2. Проверьте вкладку «Последняя активность» для просмотра результатов сканирования
3. Посмотрите, сколько новых статей было собрано по каждой теме

## Анализ статей

### Просмотр деталей статьи

1. Нажмите на любую статью из результатов поиска или дайджестов
2. Страница деталей статьи показывает:
   - Полное содержание статьи
   - Дату публикации и источник
   - Результаты анализа тональности
   - Ключевые сущности и темы
   - Связанные статьи

### Понимание метрик анализа

- **Оценка тональности**: Диапазон от -1 (негативная) до 1 (позитивная)
- **Ключевые сущности**: Важные люди, организации, места, упомянутые в статье
- **Классификация тем**: Основные темы, обнаруженные в статье
- **Оценка читабельности**: Насколько легко читается контент

## Аналитическая панель

1. Доступ к «Аналитике» из главного меню
2. Просмотр визуализаций:
   - Распределение контента по темам
   - Тенденции тональности во времени
   - Распределение источников
   - Схемы чтения
3. Настройте временной диапазон для аналитики
4. Экспортируйте отчеты в различных форматах

## Функции суперпользователя

### Доступ к панели суперпользователя

1. Войдите с учетными данными суперпользователя
2. Доступ к панели администратора из выпадающего меню профиля

### Управление пользователями

1. Просмотр всех зарегистрированных пользователей
2. Редактирование ролей и разрешений пользователей
3. Отключение или удаление учетных записей пользователей
4. Просмотр журналов активности пользователей

### Управление источниками новостей

1. Перейдите в «Источники новостей» в панели администратора
2. Просмотрите все настроенные источники
3. Добавьте новые источники новостей:
   - Укажите название источника и URL
   - Настройте HTML-селекторы для статей, заголовков, содержания и дат
   - Укажите формат даты
4. Протестируйте конфигурацию источника перед сохранением
5. Редактируйте или удаляйте существующие источники

### Конфигурация системы

1. Перейдите в «Системные настройки» в панели администратора
2. Настройте:
   - Планирование работы сканера
   - Параметры дайджестов по умолчанию
   - Настройки уведомлений по электронной почте
   - Общесистемные приоритеты тем

### Модерация контента

1. Перейдите в «Модерация контента» в панели администратора
2. Просмотрите отмеченный контент
3. Редактируйте или удаляйте неприемлемые статьи
4. Блокируйте проблемные источники

## Устранение неполадок

### Типичные проблемы

1. **Сканер не собирает статьи**
   - Проверьте ключевые слова вашей темы
   - Проверьте конфигурации источников
   - Убедитесь, что система имеет доступ к интернету

2. **Создание дайджеста занимает слишком много времени**
   - Уменьшите временной диапазон
   - Ограничьте количество тем
   - Выберите меньше источников

3. **Поиск не возвращает ожидаемые результаты**
   - Попробуйте другие ключевые слова
   - Проверьте настройки фильтров
   - Убедитесь, что существуют статьи для вашего запроса
